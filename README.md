# 📌 OnePerDay
> Gemini API 기반 개인 맞춤형 영양제 추천 웹 애플리케이션

## 📖 프로젝트 소개
사용자의 건강 상태와 신체 정보를 분석하여 Gemini API를 통해 맞춤형 영양제를 추천해 주는 웹 서비스입니다.

## 👨‍💻 담당 역할 (프론트엔드 개발 전반)
- React / TypeScript 기반 UI/UX 화면 설계 및 반응형 웹 구현
- Gemini API 연동 및 데이터 바인딩 logic 작성
- 사용자 입력 폼 예외 처리 및 상태 관리

## 🛠 기술 스택
- **Frontend**: React, TypeScript, JavaScript, HTML5, CSS3
- **AI / API**: Gemini API
- **Tools**: Git, VS Code

## ✨ 주요 기능
- **사용자 정보 입력**: 연령, 성별, 주요 건강 고민 선택
- **AI 영양제 추천**: Gemini API 기반 영양제 조합 생성 및 이유 설명
- **정보 제공**: 각 영양제별 성분 및 복용 방법 안내

## 🚀 실행 방법
```bash
# frontend 폴더로 이동 후 패키지 설치
cd frontend
npm install

# 개발 서버 실행
npm run dev
